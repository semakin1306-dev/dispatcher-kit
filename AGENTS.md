# Диспетчерская — указания агенту

Это репозиторий диспетчерской: инструмента, который ведёт параллельную работу агентов над чужим проектом. Сам проект лежит в другой папке.

## Первым делом

Проверь, есть ли в корне файл `dispatcher.project.json`.

- **Файла нет** — диспетчерская не настроена. Прежде чем делать что-либо ещё, открой [SETUP.md](SETUP.md) и проведи настройку вместе с человеком: определи факты о проекте, задай вопросы, собери конфиг, проверь установку.
- **Файл есть** — настройка пройдена. Состояние установки показывает `node setup.mjs doctor`.

## Правила работы в этом репозитории

- Своё у проекта живёт только в `dispatcher.project.json`, `dispatcher.project.mjs` и папке `project/`. Код диспетчерской под проект не правь: иначе её нельзя будет обновить.
- Настройка ничего не коммитит и не пушит. Коммит, пуш и выкат в проекте — только по слову человека.
- Тесты диспетчерской — `node --test` из корня. Перед публикацией правок — `node tools/publish-check.mjs` (без своего `.private-denylist` — с `--ci`). Правила для правок самой диспетчерской — [CONTRIBUTING.md](CONTRIBUTING.md).
- Указания агенту — только в этом файле: `CLAUDE.md` лишь импортирует его строкой `@AGENTS.md`.
- Язык общения, текстов и комментариев — русский.
