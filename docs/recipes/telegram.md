# Телеграм-бот

## Когда нужен

Агенты задают вопросы (выбрать вариант, разрешить шаг, ответить «да/нет»), а человек не у компьютера. Модуль `tg` присылает вопросы в Телеграм с кнопками вариантов; ответ из бота равен ответу со страницы — с ограничениями ниже.

## Что сделать

1. Создайте бота у @BotFather и получите токен.
2. Включите модуль в `dispatcher.project.json`: `"modules": { "tg": true }` (стартовая настройка ставит его по ответу на вопрос `modules.tg`).
3. Подключите бота — в обычном терминале из папки диспетчерской:

   ```
   node scripts/dev/tg-setup.mjs
   ```

   Утилита спросит токен скрытым вводом, попросит написать боту `/start` с того аккаунта, с которого вы будете отвечать, отправит проверочное сообщение и сохранит токен.
4. Включите «Telegram» на странице настроек (переключатель `tgBot`).

Ключи утилиты: `--store file|dpapi` — куда класть токен, `--data <папка>` — папка данных, `--proxy http://хост:порт` — прокси до Телеграма, `--wait <сек>` — сколько ждать `/start` (по умолчанию 300).

## Где хранится токен

Токен — секрет `tg-token`. Диспетчерская ищет его по порядку:

1. переменная окружения `DISPATCHER_SECRET_TG_TOKEN`;
2. файл `<папка данных>/secrets/tg-token` — на Linux и macOS только с правами `0600` и только вашим (иначе ошибка с подсказкой `chmod 600`);
3. на Windows — `<папка данных>/secrets/tg-token.dpapi`, зашифрованный DPAPI под вашей учётной записью.

По умолчанию `tg-setup` пишет на Windows в DPAPI, на остальных системах — в файл `0600`. Если задана переменная окружения, она сильнее записи — утилита предупредит. Токен не печатается и не попадает в журналы. Открытые данные — чат и пользователь, от которых бот принимает нажатия, — в `<папка данных>/tg.meta.json`.

## Что можно из бота

Ответ из бота даёт право только на ответ на вопрос, коммит и влив в `staging`. Выкат стенда и прода, сброс ветки слота и «принудительно» — только то, что человек набрал на странице. Вопрос, в котором речь о проде, выкате, релизе или сбросе, приходит в бот без кнопок ответа — отвечать на него нужно на странице.

## Подводные камни

- Пока бот диспетчерской включён, обновления Телеграма читает он: `tg-setup` получит ошибку 409. Выключите «Telegram» на странице, подключите, включите снова.
- Бот принимает нажатия только от пользователя и чата, которые прислали `/start` при подключении. Групповой чат возможен, но отвечать сможете только вы.
- Прокси по умолчанию выключен; нужен — переменная `DASH_TG_PROXY=http://хост:порт` для сервера.
- Работающая диспетчерская перечитывает токен сама: после `tg-setup` перезапуск не нужен.
