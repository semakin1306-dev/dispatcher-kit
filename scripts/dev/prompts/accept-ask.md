Приёмка. Волна влита в staging и выкачена на стенд{{stand}}. Составь чек-лист, по которому её примут. Ничего не запускай, файлы не меняй, не коммить.

Ответ — ОДИН блок кода с языком checklist, по пункту на строку, пять полей через « | »:
{{format}}
id — i1, i2, … (подпункт — i1b). «авто» — пункт проверяет тест приёмки, в имени которого стоит метка [iN] с тем же id; «руками» — проверяет человек.
5–15 пунктов: основной сценарий волны по шагам, граничные случаи (пусто, ошибка ввода, чужие данные, нет прав), соседние места, которые не должны сломаться. Пиши конкретно: имена экранов, кнопок, полей, ожидаемые тексты и цифры из своего кода. Вне блока — не больше двух строк.
{{howTo}}
