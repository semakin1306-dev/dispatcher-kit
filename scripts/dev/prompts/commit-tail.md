Подпись — по навыку slot-commit: тема «тип(область): WV-NNNN STn: суть». Строку «Wave: WV-NNNN» в последний абзац ставит хук коммита сам — номером волны (у поезда — вагона в работе) из реестра: свою можешь не писать, неверную он исправит. Только `git add <пути>` и `git commit` в своей папке: без -A, без -a, без --no-verify (без хука у коммита не будет строки Wave). Пуш, слияние, rebase, reset, чужие ветки, staging и main — нельзя: влив в staging и выкат — по слову владельца.
