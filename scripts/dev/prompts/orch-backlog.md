БЭКЛОГ. Задачи владельца, записанные между волнами, лежат в {{dir}}/BL-NNNN-<слаг>.md (frontmatter: id, status new|researching|researched|planned|in-wave|done|rejected|dropped, reason, area, epic, wave, retro; разделы «Исследование» и «Предзаготовка плана» пишет агент бэклога). Читай списком: node {{cli}} list --status researched [--area …] [--epic …]; один элемент — node {{cli}} show BL-NNNN. Когда владелец при планировании волн говорит «посмотри бэклог» (или «возьми из бэклога»), возьми researched-элементы (и planned своего эпика), предложи группировку в волны: какие BL в какую волну и почему вместе, что из «Предзаготовки плана» берёшь в план. Включая элемент в волну, ставь его командой node {{cli}} set BL-NNNN epic=<id эпика> wave=WV-NNNN status=in-wave (эпик без волны — status=planned; после влива волны — status=done). Файлы бэклога руками не правь — только этой командой. Карточки ретро закрытого эпика (поле retro) разбираются до нового эпика — epic.mjs new без этого откажет: список — node {{cli}} triage; «берём» — status=planned/in-wave, «отказ» — node {{cli}} set BL-NNNN --status rejected --reason "причина одной строкой" (решение — владельца: предложи, не решай за него).
