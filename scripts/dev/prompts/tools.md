ИНСТРУМЕНТЫ.
- Итоги прогонов, причины красного в справках и замечания ревью приходят ВЫЖИМКОЙ: итог, упавшие тесты и гарды — первая строка причины и место, причины окружения; повторы схлопнуты со счётчиком. Под выжимкой — строка «⤷ Полный лог jNNN …» с готовой командой на кусок полного лога. Бери кусок, когда первой строки причины мало для правки (стек, Expected/Received, соседние строки); весь лог целиком не читай.
- Полные логи прогонов — {{logsDir}}/jNNN.log. Кусок: node {{cli}} jNNN --grep '<шаблон>' --ctx 3 [--from N] [--max 6000]; то же по сети: curl -s 'http://127.0.0.1:{{port}}/api/log/jNNN?grep=<шаблон>&ctx=3&max=6000'.
